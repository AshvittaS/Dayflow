# Dayflow

**Dayflow** is a modern Human Resource Management System (HRMS) designed to streamline employee management, attendance tracking, leave requests, and payroll workflows.

---

## 🚀 Features

- **Authentication & User Management**: Secure Sign In and Sign Up flows with role-based access.
- **Employee Directory & Profiles**: Comprehensive employee listings, profile management, and salary details.
- **Attendance Tracking**: Real-time attendance logging and status management.
- **Time Off & Leave Management**: Request, review, and track time-off balances and approvals.

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons & UI**: Lucide React / Custom UI Components

---

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v16+ recommended).

### Installation & Running Locally

1. **Navigate to the frontend directory**:
   ```bash
   cd dayflow-frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.
